# ExcelMcp CLI Windows runtime

This package contains the self-contained Windows x64 `excelcli.exe` runtime.
Microsoft Excel 2016 or later is required. x64 Node.js selects this runtime,
including through x64 emulation on Windows ARM64. ARM64 Node.js uses the separate
native ARM64 runtime.

Install or run `@sbroenne/excelcli` instead of installing this package directly.
