Add an optional, capability-gated Office.js bridge foundation for macOS with
authenticated loopback transport, exact workbook binding, runtime requirement
set negotiation, genuine Service-to-`Excel.run` candidate routing, and explicit
install, health, upgrade, and removal lifecycle. Candidate table, table-column,
conditional-formatting, same-workbook worksheet copy/move, regular chart and
chart-configuration, ordinary local PivotTable create/delete, and
source-identifiable slicer-create actions remain disabled until real Excel
validation proves their contract parity. Ordinary local PivotTable placed-field
removal, naming, value formatting, filtering, sorting, data reads, layout,
subtotals, and grand totals are also implemented behind the same gate, with a
separate guarded public CLI/MCP acceptance runner. Field placement, listing,
and aggregation remain disabled because Office.js cannot provide the exact
source data type required by their shared contracts. Linked PivotCharts and
other advanced PivotTable features are not approximated. Disabled internal
Desktop 1.1 handlers also provide workbook-bound screenshot geometry
preparation and single-use view restoration without guessing macOS window
identity or Retina scaling.
