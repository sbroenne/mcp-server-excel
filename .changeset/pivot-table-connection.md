Inspect the workbook connection of a PivotTable and request a native connection change for one external PivotTable through both the CLI and MCP. Select the worksheet and PivotTable name to avoid changing a similarly named table on another sheet. The operation keeps the existing PivotTable and leaves connection deletion and refresh as separate steps. Excel and the provider determine whether an OLAP connection change is supported.
