Create new worksheet-source PivotTables using an existing report's cache with paired sharing options in the CLI and MCP. Reports with the same source can then connect to one slicer and share calculated fields; `read` and `list` expose their native workbook-local `cacheIndex`. The PivotTable walkthrough now includes a complete shared-slicer example and clarifies calculation and refresh limitations.
