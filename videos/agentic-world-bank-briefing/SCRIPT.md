# Agentic workflow: World Bank data to Excel and PowerPoint

**Voice:** Local Kokoro / af_heart (warm female English). No music; footage muted.

**Duration:** 161 seconds. Captions align to individually synthesized lines.

## 1. Hook

**Time:** 0–13s

    This is an agentic workflow. One AI agent researched World Bank data, analyzed it in Excel, and built a PowerPoint briefing. All from one request, in thirty-nine minutes. Nobody stepped in.

## 2. The ask

**Time:** 13–27s

    It starts with a plain-English request to an AI agent in GitHub Copilot CLI. One hundred and twelve words, sent once, with no follow-ups.

## 3. Research

**Time:** 27–42s

    First, the agent does the research. It finds the World Bank's official indicators, tests the data service, and pulls twenty-five years for twenty-five economies. Then it checks for gaps.

## 4. Excel MCP Server

**Time:** 42–72s

    Next, Excel MCP Server. The agent drives the real Excel app. It loads the data with Power Query, builds a Data Model with DAX measures, and adds analysis sheets, charts, and a PivotTable. A checks sheet tests the key numbers. When a step fails, the agent reads the error and tries another way.

## 5. Hand-off

**Time:** 72–82s

    Before it designs a single slide, the agent reads its results back from the workbook. Every number on a slide comes from Excel.

## 6. PowerPoint MCP Server

**Time:** 82–110s

    Now, PowerPoint MCP Server. The agent designs one slide as a template, exports it as a picture, and looks at it, the way a designer would. Then it builds the other slides, with native, editable charts, headlines that state the insight, sources, and speaker notes. It ran into a chart bug and a PowerPoint crash, and recovered on its own.

## 7. The briefing

**Time:** 110–130s

    The result is a seven-slide briefing. China's income per person grew almost six times. The gap between the richest and poorest economies halved. And internet use went from seven percent to ninety.

## 8. Scoreboard

**Time:** 130–147s

    One request. Six hundred and twelve tool calls. Two MCP servers, and one AI model. We checked the headline numbers against the World Bank. You still review the result, but the heavy lifting is done.

## 9. How this video was made

**Time:** 147–161s

    How was this video made? With another agentic workflow. An AI agent recorded the run, cut the footage, wrote the script, and built this video with HyperFrames. A person approved it at key points.
